# QRCode Video

Microsite simples em HTML/CSS para apresentar vídeos acompanhados de QR Codes e links sociais.

---

## 📌 Objetivo

Este projeto fornece uma estrutura leve para criar páginas de vídeo acessíveis via QR Code, ideais para:

- portefólios  
- apresentações  
- catálogos digitais  
- demonstrações rápidas para clientes  

---

## 🧱 Estrutura do Projeto
```
qrcode-video/
│
├── index.html          │ Página inicial
├── videos/             │
│   └── video1.html     │ Página de vídeo com QR Code e links sociais
│
└── assets/             │ Imagens, ícones e outros recursos
```


---

## 🎨 Funcionalidades

- Página de vídeo dedicada com layout limpo  
- QR Code integrado para acesso rápido  
- Secção de links sociais  
- HTML e CSS minimalistas, fáceis de adaptar  
- Compatível com GitHub Pages  

---

## 🚀 Deploy

O projeto pode ser publicado diretamente com **GitHub Pages**.  
Basta ativar o Pages no repositório e apontar para a branch principal.
